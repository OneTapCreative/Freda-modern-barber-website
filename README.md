# Modern Barber Website — OneTap Creative

A mobile-first, one-page barber website template with a modern rose, charcoal, and soft blush color system, inspired by the conversion structure used for the DJ JRV project.

## Preview
Open `index.html` in a browser, or run a local web server:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Customize before publishing
Search and replace these demo items:

- `EDGE & CRAFT` — barber or barbershop name
- `Stockton, California` — city and state
- `(209) 555-0123` — phone number
- `hello@example.com` — email address
- `123 Main Street` — shop address
- Service names, prices, and durations
- Business hours
- Review text and names
- Google Maps link
- Instagram link
- Hero and gallery image URLs

## Booking integration
The demo booking form currently displays a confirmation message only. Replace it with one of these options:

- Square Appointments booking link or widget
- Booksy
- Squire
- Fresha
- TheCut
- Vagaro
- Formspree, Basin, or another contact-form endpoint

For a basic external booking link, change each `href="#booking"` booking button to the client's booking URL.

## Deploy to Vercel
1. Upload this folder to a GitHub repository.
2. In Vercel, choose **Add New → Project**.
3. Import the repository.
4. Keep framework preset as **Other**.
5. Click **Deploy**.

## Deploy to Netlify
Drag the complete folder into Netlify Drop, or connect the GitHub repository.
